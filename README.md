# skript-placeholders-fork
Integrating placeholders into Skript.

> [!IMPORTANT]
> This addon requires Skript 2.15.0 or later.  
> 
> This is a fork of the skript-placeholders addon [skript-placeholders (by APickledWalrus)](https://github.com/APickledWalrus/skript-placeholders/).  
> 
> The addon was written using AI, but I have tested it myself, and it works perfectly.  
> 
> This version removes support for the MVdWPlaceholderAPI, as it is deprecated!  
> 
> I am not the author of this addon; I merely rewrote it for the new version of Skript.  
>
> This addon has the exact same documentation as the original skript-placeholders. The syntax is unchanged, so everything should work without any changes to your server files. Perhaps, if you request it, I'll add something new to the addon.
>

> If you encounter any bugs, please report them using the [issues](https://github.com/der3kyy/skript-placeholders-fork/issues) tab.

This addon allows you to use and register placeholders using PlaceholderAPI.  
PlaceholderAPI must be installed for this addon to work.
